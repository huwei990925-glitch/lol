# LOL 战术与数值推演系统 (iPhone 专属独立版)

一款 **100% 运行在手机上、完全不依赖电脑** 的英雄联盟国服版本数据分析与多模型战术推演应用。

---

## 🌟 核心功能

### 1. ⚔️ 移动端即时对局沙盘 (5v5峡谷 / 大乱斗)
- **英雄池已直连腾讯国服官方 CDN**，自动同步当前国服全部 173 位官方英雄；
- 随手点选我方英雄 vs 敌方核心，勾选战局节点与敌方已出的核心装备；
- 一键呼叫 AI，手机直接推导出**对线期线权优先级、单杀换血线、首件质变出装及克制装顺序**！

### 2. 🤖 多模型与多协议全面支持 (自由切换)
在【设置】中可以随时一键切换不同的 AI 提供商与端点：
- **Google Gemini 原生**：默认端点 `/v1beta/models/{model}:generateContent`（默认 `gemini-3.8-flash`）；
- **OpenAI Chat**：端点 `/v1/chat/completions`（如 `gpt-4o`, `gpt-4-turbo` 等）；
- **OpenAI Responses (最新协议)**：端点 `/v1/responses`；
- **Anthropic Claude**：端点 `/v1/messages`（如 `claude-3-5-sonnet-20240620` 等）；
- **自定义端点支持**：支持变量占位符 `{model}`，自定义任意反代/中转站网关路径与 Key！

### 3. 🛡️ 装备与数值实验室 (Stats Lab)
- **腾讯国服官方全量装备库**：直连拉取 704 件装备，带有官方高清图标、金币与被动属性；
- 双抗减伤曲线滑块、有效生命值（EHP）与穿甲衰减计算器；
- 技能急速（AH）与大招实际 CD 换算。

### 4. 🌀 海克斯乱斗专区 (Mayhem)
- 收录棱彩、黄金、白银三阶强化符文（如【珠光护手】技能暴击、【连环打击】双重咒刃）。
- 模拟符文与出装的乘区联动。

## 📱 iPhone 安装与使用指引

### 最优推荐：Safari 一键“添加到主屏幕”（永不掉签，秒开独立 App）
1. 用 iPhone 自带的 **Safari 浏览器** 打开本网页；
2. 点击 Safari 底部的 **【分享】** 按钮（方框带向上箭头的图标）；
3. 往下拉找到并点击 **【添加到主屏幕】**；
4. 手机桌面上会出现一个黑金风格的 **LOL推演** 专属图标；
5. 点击图标启动，**全屏运行、无浏览器地址栏、离线秒开，体验与从 App Store 下载的 App 毫无区别，且永远不会像自签名那样 7 天掉签！**

---

## ⚙️ 首次使用配置
1. 点击底部最右侧的 **【设置】** 导航；
2. **选择协议预设**（Gemini / OpenAI Chat / OpenAI Responses / Anthropic）；
3. 填入你的 **Base URL** 与 **API 请求端点**；
4. 填入你的 **API Key**（数据保存在你的手机内部，绝不上云）；
5. 输入模型名称（如 `gemini-3.8-flash` / `gpt-4o` 等）；
6. 点击 **【测试接口连接】**，提示连接成功即可开始畅快推演！
